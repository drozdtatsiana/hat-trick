# Hat-Trick: хоккейная школа

Одностраничный сайт учебного проекта — хоккейной школы «Hat-Trick» (Минск). Включает главный экран, блок «О школе» с тренерами, программы, отзывы, футер с контактами и диалог записи на тренировку.

**Демо:** https://drozdtatsiana.github.io/hat-trick/

> Учебный проект. Школа, адрес, контакты и отзывы вымышленные.

## Структура

```
app/            исходники: HTML-разметка, SCSS, JS, изображения, шрифты
docs/           собранный сайт, который публикует GitHub Pages
gulpfile.js     сборка и локальный сервер
package.json    зависимости и скрипты
```

## Стек

- HTML5, SCSS (модули `@use`), адаптивная вёрстка
- Vanilla JavaScript: модальное окно записи на `<dialog>`, мобильное меню-бургер
- Gulp 4: компиляция SCSS, минификация CSS/JS, сборка SVG-спрайта, оптимизация изображений, Browsersync
- Шрифты: Geist Mono, TiltWarp

## Запуск локально

Требуется Node.js (LTS).

```bash
npm install
npx gulp
```

Сайт откроется на http://localhost:3000. Gulp следит за файлами в `app/` и перезагружает страницу при изменении.

## Сборка

```bash
npx gulp build
```

Готовые файлы попадут в `dist/`. GitHub Pages публикует папку `docs/`, поэтому после сборки скопируйте результат:

```bash
cp -r dist/. docs/
```

Затем закоммитьте `docs/` и отправьте в `main`. В настройках репозитория Settings → Pages выберите ветку `main` и папку `/docs`.

## Что ещё не готово

- Форма записи (`dialog.booking`) ничего не отправляет: бэкенд или внешний сервис заявок не подключён.
- Телефон, e-mail и ссылки соцсетей — заглушки.
- Ссылки в футере («Условия», «Политика конфиденциальности», «Книга жалоб и предложений») ведут на `#`.

## Структура стилей

Адаптив собран в одном файле по брейкпоинтам 1200 / 960 / 900 / 600 / 460 / 360 px. Базовые стили должны идти раньше адаптивных, а селекторы секций (`section.hero`, `footer.footer` и т. д.) имеют повышенную специфичность, чтобы адаптив не перебивался базовыми правилами.
